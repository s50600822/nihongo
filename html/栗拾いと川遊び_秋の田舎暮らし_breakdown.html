Grammar: こんにちは。くまです。 is the standard greeting with name + polite copula. 今日は栗拾いに来ました。 uses the topic 今日は (today [topic]) + locative 栗拾いに (for chestnut picking = ASR error クリい) + polite past 来ました (came): "Today [I] came to pick chestnuts." たくさん取れたら栗を炊いて食べたいと思います。 uses the conditional たくさん取れたら (if [I] can gather a lot = 取れる + たら) + object 栗を (chestnuts [object]) + te-form consecutive 炊いて (cook = 炊く + て) + desiderative 食べたい (want to eat = 食べる + たい) + quotative と (that) + polite 思います (think): "If [I] can gather a lot, [I] want to cook and eat chestnuts." The conditional たら marks the gathering as the prerequisite for cooking. 今回は手袋を忘れてしまったので、棘が手に刺さらないように足で剥いていきます。 uses the topic 今回は (this time [topic]) + object 手袋を (gloves [object] = ASR error 日み) + completion past 忘れてしまった (forgot = 忘れる + て + しまった) + causal ので (because) + subject 棘が (thorns [subject] = ASR error トが) + locative 手に (into [my] hand) + negative 刺さらない (won't pierce = 刺さる + らない) + adverbial ように (so that) + instrumental 足で (with [my] feet) + directional progressive 剥いていきます (will go peel = 剥く + ていく): "This time [I] forgot [my] gloves, so [I'll] peel [them] with [my] feet so [the] thorns don't pierce [my] hands." The ASR error 日み for 手袋 is a severe phonetic fragmentation. The ASR error トが for 棘が is a phonetic near-miss where とげが became とが. The pattern [negative verb] + ように marks purpose/prevention. 大きな栗が2つ取れました。 uses the subject 大きな栗が (big chestnuts [subject]) + number 2つ (two) + polite past potential 取れました (could get = 取れる + ました): "[I] got two big chestnuts." ここでとある生き物を発見。 uses the locative ここで (here) + indefinite determiner とある (a certain) + object 生き物を (creature [object]) + noun 発見 (discovery): "Here [I] discovered a certain creature." The sentence omits the verb, using the noun alone for dramatic effect. ミヤマカラスバエを見つけました。 uses the object ミヤマカラスバエを (Miyama crow fly [object]) + polite past 見つけました (found): "[I] found a Miyama crow fly." The ASR error 宮山カラス揚げ派 for ミヤマカラスバエ is a severe phonetic degradation where the insect name was broken into nonsensical fragments (宮山 + カラス揚げ + 派). The Miyama crow fly (ミヤマカラスバエ) is a species of fly found in mountainous areas of Japan. どんどん拾っていきます。 uses the adverb どんどん (steadily) + directional progressive 拾っていきます (will go pick up): "[I'll] keep picking steadily." やったぜ。 uses the past casual やった (did it) + emphatic masculine particle ぜ: "Did it, ze." 大きな栗もたくさん取れました。 uses the subject 大きな栗も (big chestnuts [also]) + adverb たくさん (lots) + polite past potential 取れました (could get): "[I] also got lots of big chestnuts." 栗を探していると野生動物の足跡も発見。 uses the object 栗を (chestnuts [object]) + progressive 探してる (searching = 探す + している) + temporal と (when) + possessive 野生動物の (wild animal's) + object 足跡も (footprints [also]) + noun 発見 (discovery): "While searching for chestnuts, [I] also discovered wild animal footprints." The pattern [progressive verb] + と marks a discovery made during the ongoing action. せっかく山に来たのでお決まりの川遊びもしていきます。 uses the adverb せっかく (specially; with effort) + locative 山に (to the mountain = ASR error 変に) + past 来た (came) + causal ので (because) + possessive お決まりの (the usual) + object 川遊びも (river play [also]) + directional progressive していきます (will go do): "Since [I] came to the mountain specially, [I'll] also do the usual river play." The ASR error 変に for 山に is a phonetic mismatch where やま became へん.

Grammar: 仕掛けは使わず網と手で魚を捕まえてみました。 uses the topic 仕掛けは (tackle [topic]) + negative zu-form 使わず (without using = 使う + わず) + instrumental 網と手で (with a net and hands) + object 魚を (fish [object]) + te-form attempt 捕まえてみました (tried catching = 捕まえる + て + みる + ました): "[I] tried catching fish with a net and [my] hands without using tackle." The pattern [verb stem] + わず is the literary negative form meaning "without [verb]ing," here used in casual speech for conciseness. 石をひっくり返すと生き物を発見。 uses the object 石を (stone [object]) + verb ひっくり返す (flip over) + temporal と (when) + object 生き物を (creature [object]) + noun 発見 (discovery): "When [I] flipped over a stone, [I] discovered a creature." The pattern [plain verb] + と marks immediate discovery or result. 川の端に追い詰めてから手で捕まえました。 uses the locative 川の端に (to the river's edge) + te-form 追い詰めて (cornering = 追い詰める + て) + temporal から (after) + instrumental 手で (with [my] hand) + polite past 捕まえました (caught): "After cornering [it] at the river's edge, [I] caught [it] with [my] hand." 早速手長エビをゲット。 uses the adverb 早速 (immediately) + object 手長エビを (long-armed shrimp [object]) + loanword noun ゲット (get): "Immediately got a long-armed shrimp." The loanword ゲット functions as a casual verb substitute. 立派な手長エビでした。 uses the na-adjective attributive 立派な (splendid) + subject 手長エビした (was a long-armed shrimp): "[It] was a splendid long-armed shrimp." ゲット。 is the loanword alone for excited confirmation. せっかく捕まえましたが逃します。 uses the adverb せっかく (with effort) + polite past 捕まえました (caught) + contrastive が (but) + polite 逃します (will release): "Even though [I] caught [it] with effort, [I'll] release [it]." The contrastive が marks the catch-and-release ethic. ごめんね。バイバイ。うん。早い。 uses apology + farewell + affirmation + i-adjective describing the creature's quick escape: "Sorry, ne. Bye-bye. Yes. Fast." カエルも捕まえました。 uses the noun カエルも (frog [also] = ASR error 皮ム / 川ム) + polite past 捕まえました (caught): "[I] also caught a frog." The ASR errors 皮ム and 川ム are severe phonetic degradations where かえる became unrecognizable fragments. ゲット。カエル。 uses the loanword + noun for excited enumeration. ここからはガサガサタイムです。 uses the locative ここからは (from here [topic]) + onomatopoeia ガサガ (gasa-gasa [net fishing]) + loanword タイムです (is time): "From here [it's] gasa-gasa time." Gasa-gasa (ガサガサ) is a Japanese term for wading into shallow water with a net to catch aquatic creatures. 草の根や岩の隙間に網を突っ込みます。 uses the locative phrase 草の根や岩の隙間に (into grass roots and rock crevices) + object 網を (net [object]) + polite 突っ込みます (will thrust into): "[I] thrust the net into grass roots and rock crevices." 魚が網に入りました。 uses the subject 魚が (fish [subject]) + locative 網に (into the net) + polite past 入りました (entered): "Fish entered the net." The ASR error さなが網に for 魚が網に is a phonetic near-miss where さかなが became さなが. 他にもたくさんの魚を捕まえましたがリリースしました。 uses the adverb 他にも (also other [fish]) + adverb たくさんの (many) + object 魚を (fish [object]) + polite past 捕まえましたが (caught, but) + loanword verb polite リリースしました (released): "[I] caught many other fish too but released [them]." The loanword リリース (release) is commonly used in Japanese fishing contexts for catch-and-release. この後も水面と睨めっこしていると水底に綺麗なカワラが沈んでいました。 uses the temporal この後も (after this too) + object 水面と (with the water surface) + progressive 睨めっこしている (having a staring contest = 睨めっこ + する + ている) + temporal と (when) + locative 水底に (at the river bottom) + adjective 綺麗な (beautiful) + subject カワラが (riverbed stone [subject]) + progressive past 沈んでいました (was sinking = 沈む + んで + いました): "After this too, while having a staring contest with the water's surface, a beautiful riverbed [stone] was sinking at the river bottom." The ASR error 水面とにラめっこ for 水面と睨めっこ is a severe phonetic fragmentation where にらめっこ became にラめっこ. The ASR error 皮の中に綺麗なが沈んでいました for 水底に綺麗なカワラが沈んでいました is a cascade of errors: 川底/水底 became 皮の中に, and カワラが became 綺麗なが. カワラ (河原/瓦) refers to riverbed stones or tiles, here likely meaning a beautiful stone at the river bottom. 秋を感じます。 uses the object 秋を (autumn [object]) + polite 感じます (feel): "[I] feel autumn." え、なんかちょっと変な色するな。 uses the surprise marker え (huh?) + indefinite なんか (somehow) + adverb ちょっと (a bit) + na-adjective 変な (strange) + noun 色 (color) + verb する (do/have) + particle な (assertive): "Huh, somehow [it] has a slightly strange color, na." The vlogger is commenting on the color of something in the water. そろそろ帰ります。 uses the adverb そろそろ (about time) + polite 帰ります (will go home): "[It's] about time to go home."

05 Key Grammar Patterns Summary

〜ていく / 〜てくる (Directional Progressive and Perfective)
剥いていきます (will go peel), 拾っていきます (will go pick up), 川遊びもしていきます (will also go do river play), 詰めていきます (will go pack), 炊いていきます (will go cook). The grammar of forward-moving activities in foraging, cooking, and bento preparation.
〜たら (Conditional) and 〜たい (Desiderative)
たくさん取れたら (if [I] can gather a lot), 食べたいと思います (want to eat and think), 山が見える畑でお弁当を食べようと思います (think [I'll] eat bento in a field with mountain view). The grammar of conditional intentions and expressed desires.
〜てみる (Attemptive) and 〜てしまう (Completion)
捕まえてみました (tried catching), 忘れてしまった (forgot [completely]), 即買いしちゃいました (bought immediately [completely]). The grammar of attempted actions and completed states.
〜やすい / 〜にくい (Ease and Difficulty)
剥きやすかった (was easy to peel), 集まりにくくなる (become difficult to gather) [from previous files]. The grammar of ease and difficulty suffixes attached to verb stems describing physical tasks.
〜ように (Purpose and Prevention)
棘が手に刺さらないように (so thorns won't pierce [my] hands), 使わず (without using). The grammar of purpose clauses and negative-purpose prevention in foraging and fishing contexts.
〜が (Contrastive) and 〜のに (Concessive)
せっかく捕まえましたが逃します (even though [I] caught [it], [I'll] release [it]), だいぶ見たのにな (even though [I] looked a lot [from previous files]). The grammar of contrast and concession in catch-and-release ethics and frustrated observation.
〜そう (Appearance Inference)
楽しそうでした (seemed fun), なさそうね (seems like there aren't any [from previous files]). The grammar of visual and contextual inference about states and emotions.
