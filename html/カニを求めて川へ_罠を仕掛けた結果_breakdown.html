"Hello. [It's] Kuma. Today [I'm] going to a nearby river to search for mitten crabs called zugani. If [I] catch [some], [I] want to eat just a little. [They're] quite difficult to catch with bare hands, so [I'll] catch [them] by setting traps. This day the water was quite cold and [I] didn't want to get in, so [I'll] proceed while balancing on the rocks. [I'll] search for points to set traps. Yes. Ah, there are so many crabs. Ah, a frog. Grammar: こんにちは。くまです。 is the standard greeting with name + polite copula. 今日は近くの川でズガニと呼ばれているモクズガニを探しに行きます。 uses the topic 今日は (today [topic]) + locative 近くの川で (at a nearby river) + passive attributive phrase ズガニと呼ばれている (called zugani = 呼ぶ + られる + ている) + object モクズガニを (mitten crabs [object] = ASR error 木ズガニ) + purposive 探しに行きます (go search = 探す + し + に + 行く): "Today [I'm] going to a nearby river to search for mitten crabs called zugani." The ASR error 図ガニ for ズガニ is a phonetic near-miss. The ASR error 木ズガニ for モクズガニ is a phonetic degradation where もく became 木. モクズガニ (Eriocheir japonica) is the Japanese mitten crab, a popular seasonal food in autumn. 捕まえたら少しだけいただきたいと思います。 uses the conditional 捕まえたら (if [I] catch = 捕まえる + たら) + extent 少しだけ (just a little) + humble desiderative いただきたい (want to eat/receive = いただく + たい) + quotative と (that) + polite 思います (think): "If [I] catch [some], [I] want to eat just a little." The humble verb いただく is used instead of 食べる for politeness. 小さい頃からこの時期になるとよく見かけるカニです。 uses the temporal 小さい頃から (since childhood) + temporal clause この時期になると (when it becomes this season = なる + と) + adverb よく (often) + verb 見かける (catch sight of) + polite copula です: "[They're] crabs [that I] often see around this time since [I was] small." The pattern [time] + なると marks a habitual seasonal occurrence. ズガニは警戒心が強く人の気配を感じるとすぐに岩陰に隠れます。 uses the topic ズガニは (mitten crabs [topic]) + subject 警戒心が (wariness [subject]) + i-adjective adverbial 強く (strongly) + object 人の気配を (human presence [object]) + conditional 感じると (if [they] sense = 感じる + と) + adverb すぐに (immediately) + locative 岩陰に (into rock shadows) + polite 隠れます (hide): "Mitten crabs are very wary and hide in rock shadows as soon as [they] sense human presence." The pattern [plain verb] + と marks an immediate consequence. The ASR error ズばには for ズガニは is a phonetic truncation. 素手で捕まえるのはかなり難しいので罠を仕掛けて捕まえます。 uses the nominalized topic 素手で捕まえるのは (catching with bare hands [topic] = ASR error 素で) + adverb かなり (quite) + i-adjective 難しい (difficult) + causal ので (because) + object 罠を (trap [object]) + te-form 仕掛けて (setting = 仕掛ける + て) + polite 捕まえます (will catch): "[They're] quite difficult to catch with bare hands, so [I'll] catch [them] by setting traps." Ah, there are so many crabs." The ASR error 川ム for カニ is a severe phonetic degradation. あ、カエル。何がいる？ uses the realization + noun + question: "Ah, a frog. What's there?" あ、トノサマガエルか。 uses the realization + noun + question か: "Ah, is it a pond frog?" 02 Setting the Trap — Fish Heads and Environmental Ethics

Ii pointo ga mitsukatta node sassoku junbi ni torikakarimasu. Konkai wa wana no shikake ni aozakana no atama wo tsukaimasu. Nioi ga tsuyoi hodo zugani-tachi wa yotte kimasu. Basho ni yotte wa shikake ga kinshi sarete iru tokoro ya gyougyoken de tsukamaeru koto ga kinshi sarete iru tokoro mo aru node shizen ya chiiki no ruuru wo mamotte tanoshimimashou. Sore dewa sassoku shikakete ikimasu. Wana ga nagasarenai you ni eda ni kukuritsukemashita. Shikake ga owatta no de kono hi wa kaerimasu.
"[I] found a good spot so [I'll] get started on preparations immediately. This time [I'll] use fish heads for setting the trap. The stronger the smell, the more the mitten crabs gather. Depending on the location, there are places where trapping is prohibited and places where catching is prohibited by fishing rights, so let's enjoy while following nature and local rules. Well then, [I'll] set [the trap] immediately. [I] tied [it] to a branch so the trap wouldn't be washed away. Since the setup is finished, [I'll] go home this day."

03 First Retrieval — One Small Crab and River Play

The ASR error 揚げさ for 油揚げ is a severe phonetic degradation. カニ味噌も入れていきます。 uses the object カニ味噌も (crab miso [also]) + directional progressive 入れていきます: "[I'll] also put in crab miso." カニ味噌 refers to the hepatopancreas (tomalley) of the crab, a delicacy in Japanese crab cuisine. ここでお腹の部分も入れます。 uses the locative ここで (here) + possessive お腹の (belly's) + noun 部分も (part [also]) + polite 入れます (will put in): "Here [I'll] also put in the belly part." あとは炊くだけです。 uses the topic あとは (after that [topic]) + verb 炊くだけ (just cook = 炊く + だけ) + copula です (is): "After that [it's] just cooking." ご飯が炊けるまでの間にトッピング用のミツバを探しに行きます。 uses the temporal clause ご飯が炊けるまでの間に (while until the rice cooks = 炊ける + まで + の間に) + attributive トッピング用の (for topping) + object ミツバを (mitsuba [object] = ASR error 三葉) + purposive 探しに行きます (go search = 探す + し + に + 行く): "While the rice is cooking, [I'll] go search for mitsuba for topping." The ASR error 三葉 for ミツバ is a kanji reading substitution (三葉 = three leaves, read みつば). Mitsuba (Cryptotaenia japonica) is a Japanese herb used as a garnish. もうちょっと欲しいな。 uses the adverb もう (more) + adverb ちょっと (a bit) + i-adjective 欲しい (want) + particle な (wish): "[I] want a bit more, na." ここに生えてる。 uses the locative ここに (here) + progressive 生えてる (is growing = 生える + ている): "[It's] growing here." 取り終わったので帰ります。 uses the compound verb past 取り終わった (finished picking = 取る + 終わる + た) + causal ので (because) + polite 帰ります (will go home): "Since [I've] finished picking, [I'll] go home." いい感じに炊き上がりました。 uses the colloquial phrase いい感じに (nicely; well) + compound verb polite past 炊き上がりました (finished cooking = 炊き上がる + ました): "[It] cooked up nicely." 先ほど積んできたミツバを乗せたら完成です。 uses the temporal 先ほど (just now) + compound verb attributive 積んできた (picked and brought = 積む + て + くる + た = ASR error 積んできた is correct) + object ミツバを (mitsuba [object]) + conditional 乗せたら (if [I] put on = 乗せる + たら) + noun 完成です (is complete): "If [I] put the mitsuba [I] picked earlier on top, [it's] complete." The humble いただく frames the eating as receiving the food gratefully. 中にしっかりカニ味噌が詰まってます。 uses the locative 中に (inside) + adverb しっかり (firmly) + subject カニ味噌が (crab miso [subject]) + progressive 詰まってます (is packed = 詰まる + ている + ます): "Crab miso is packed firmly inside." 残った足は翌日の味噌汁に入れます。 uses the past attributive 残った (remaining = 残る + た) + subject 足は (legs [topic]) + possessive 翌日の (next day's) + locative 味噌汁に (into miso soup) + polite 入れます (will put in): "The remaining legs [I'll] put in tomorrow's miso soup." 美味しくいただきました。 uses the adverbial i-adjective 美味しく (deliciously = 美味しい + く) + humble polite past いただきました (ate/received): "[I] ate deliciously." ごちそうさまでした。 uses the set phrase marking the end of a satisfying meal: "[That was] a feast."

07 Key Grammar Patterns Summary

〜ほど (Proportionality: The More… The More)
匂いが強いほどズガニたちは寄ってきます (the stronger the smell, the more crabs gather). The grammar of proportional relationships using ほど attached to adjectives.
〜ていく / 〜てくる (Directional Progressive)
探していきます (will go search), 仕掛けていきます (will go set), 入れていきます (will go put in), 調理をしていきます (will go cook), 持って帰ってきました (brought home). The grammar of forward-moving and return actions in trapping and cooking contexts.
〜にくい / 〜やすい / 〜っぽい (Difficulty, Ease, and Resemblance)
分かりづらい (hard to tell), 開けやすかった (was easy to open) [from previous files], 赤ちゃんっぽい (looks like a baby). The grammar of difficulty, ease, and approximation suffixes.
〜ことにする / 〜ことにしました (Decision)
挑戦することにしました (decided to challenge), くくり付けることにしました (decided to tie). The grammar of making decisions and forming resolutions.
〜が (Contrastive) and 〜のに (Concessive)
7匹捕まえましたが、小さなメスは逃がします (caught 7, but release small females), 分かりづらいですが (hard to tell, but). The grammar of contrast and selective release in sustainable foraging.
〜だけ (Restrictive) and 〜分 (Portion)
食べる分だけ持って帰ります (take home only what [I'll] eat), 炊くだけです (just cook). The grammar of restriction and portion in sustainable harvesting.
