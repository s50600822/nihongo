Grammar: めっちゃ大きい。でかない。 uses the Kansai intensifier めっちゃ (very) + i-adjective 大きい (big), followed by the slang i-adjective でかい (huge) + negative question ない (isn't it?). The pattern [i-adjective] + ない forms a tag question seeking agreement. あれ何のライト? 2つ光ってるよ。 uses the demonstrative あれ (that) + question 何のライト (what light?) + number 2つ (two) + progressive 光ってる (are shining = 光る + ている): "What light is that? Two are shining." The lights are the reflected eye-shine of crabs in the darkness. 3匹とも色違う。 uses the counter 匹 (animals) + inclusive particle とも (all/each) + compound verb 色違う (differ in color = 色 + 違う): "All three are different colors." 真っ暗。 is the noun 真っ暗 (pitch black) used as an exclamation. すごいな。めっちゃ荒れてる。 uses the exclamatory な + Kansai intensifier めっちゃ + progressive 荒れてる (is overgrown = 荒れる + ている): "Amazing. It's so overgrown." これ多イノシシ荒らしたとこや。 uses the topic これ (this) + adverb 多分 (probably) + past attributive イノシシ荒らした (wild boar-ravaged = 荒らす + た) + nominalizer とこ (place) + Kansai copula や (is): "This is probably where wild boars ravaged." The pattern [past verb] + とこ nominalizes the action into a place. 横もボコボコ。 uses the subject 横も (the sides too) + onomatopoeia ボコボコ (bumpy; pockmarked): "The sides are all bumpy too." 何もいてまへん。 uses the Kansai negative form いてまへん (there isn't anything = いる + まへん) instead of standard いません. The Kansai negative へん replaces standard ない. 何もいてません。 is the standard polite negative for emphasis. あれカニやでっか。 uses the demonstrative あれ (that) + noun カニ (crab = ASR error 明日かも) + Kansai copula や (is) + question でっか (is it? = だ + いか): "Is that a crab?" The ASR error 明日かも for カニや is a severe phonetic mismatch. けどこっちの池のカニおるやつの方がめちゃくちゃでかい。 uses the contrastive ど (but) + locative こっちの池の (this pond's = ASR error 家の) + subject カニおるやつの方が (the crabs that exist [here] are more = カニ + おる + やつ + の方が) + adverb めちゃくちゃ (absurdly) + i-adjective でかい (huge): "But the crabs in the pond over here are way bigger." The pattern [noun] + の方が marks comparative superiority. The Kansai verb おる (exist animate) replaces standard いる. 君はまだ小さい。もうちょっと頑張りな。 uses the address 君は (you [topic]) + adverb まだ (still) + i-adjective 小さい (small) + imperative 頑張りな (try harder = 頑張る + な): "You're still small. Try a bit harder." The vlogger is speaking to a crab or beetle. ヒラタで大きいなあ。 uses the noun ヒラタ (flat stag beetle = ASR error 飛車安で) + copula で (is) + i-adjective 大きい (big) + exclamatory なあ: "It's big for a flat stag beetle." The ASR error ゴミムシ (rove beetle) for コオロギ is a semantic mismatch; both are insects but rove beetles don't jump. いました。いました。 uses the polite past existential いました (there was one) repeated for confirmation. めっちゃ跳ねるやん。 uses the Kansai sentence-ending やん (isn't it? = じゃん): "It really hops, doesn't it?" どっか行っちゃった。 uses the colloquial どっか (somewhere = どこか) + completion 行っちゃった (went away = 行く + てしまう + た): "It went somewhere." 程のサイズや。 uses the noun 程 (about/degree = ASR error 低) + possessive の + noun サイズ + Kansai copula や: "It's about that size." The ASR error 低 (low) for 程 (degree) is a phonetic mismatch. ちょっとこっち向いて。 uses the imperative 向いて (turn = 向く + て): "Turn this way a bit." お目目が可愛い。 uses the baby-talk reduplication お目目 (eyes = ASR error お目が) + subject が + i-adjective 可愛い (cute): "Your eyes are cute." 草がすごい茂ってる。 uses the progressive 茂ってる (is overgrown = 茂る + ている = ASR error さがすごいしげってる): "The grass is really overgrown." The ASR error 独どしい for 毒っぽい is a phonetic near-miss. 何のキノコやろか。 uses the Kansai question やろか (I wonder = だろうか): "I wonder what mushroom this is." 虫おった uses the Kansai past existential おった (there was = いた): "There was a bug." 危ない。もうすぐで踏んじゃうところやったね。 uses the i-adjective 危ない (dangerous) + temporal もうすぐで (just about to) + potential negative completion 踏んじゃう (might step on = 踏む + じゃう) + nominalizer ところ (point) + Kansai past copula やった (was = ASR error やったね): "That was a close call, you almost stepped on it." The pattern [verb] + ところだった marks a near-miss. 今日はめっちゃ長靴、ぶっといやつ履いてんの。 uses the topic 今日は (today [topic]) + Kansai intensifier めっちゃ (really) + noun 長靴 (rubber boots) + i-adjective ぶっとい (thick = ASR error ぶ靴いい) + pronoun やつ (ones) + progressive 履いてんの (am wearing = 履く + ている + の): "Today I'm wearing really thick boots."

05 Key Grammar Patterns Summary

Kansai Negative Forms: へん / まへん / えへん
何もいてまへん (there's nothing here = いません), 見えへんかった (couldn't see = 見えなかった), 入ってこうへん (don't come in = 入ってこない), わからん (don't know = わからない). The grammar of Kansai dialect negative verb conjugations replacing standard ない with へん or ん.
Kansai Copula and Sentence Endings: や / やん / やな / やろか
イノシシ荒らしたとこや (is where boars ravaged = だ), めっちゃ跳ねるやん (really hops, doesn't it = じゃん), 美味しそうなキノコやな (looks tasty, doesn't it = だな), 何のキノコやろか (I wonder what mushroom = だろうか). The grammar of Kansai dialect sentence-final copula and modal particles.
〜てしまう / 〜ちゃう (Completion and Regret)
踏んじゃうところやった (almost stepped on it), 逃げちゃった (it escaped), 即買いしちゃいました (bought immediately) [from previous files]. The grammar of completed actions with connotations of accident, regret, or suddenness.
〜たらな / 〜たらなって思う (Hope and Wish)
見つけられたらなって思ってます (I think it'd be nice if I could find [them]). The grammar of expressed wishes using conditional + な + quotative 思う.
〜っぽい (Approximation and Resemblance)
毒っぽい (poisonous-looking), げちゃっぽい (grayish), 赤っぽい (reddish). The grammar of approximation suffix っぽい attached to nouns and adjectives to describe color, quality, and resemblance.
〜そう (Appearance and Inference)
美味しそう (looks tasty), いそう (seems like there is), 楽しそう (seems fun) [from previous files]. The grammar of visual and contextual inference through appearance-marking そう.
Passive and Suffering Passive
鹿に食われてる (is being eaten by a deer), 誰かに食べられてる (is being eaten by something), 切り倒されてた (had been cut down), かじられてる (is being gnawed on). The grammar of direct passive describing actions suffered by mushrooms and trees.
